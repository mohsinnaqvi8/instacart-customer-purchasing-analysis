# Instacart Customer Purchasing Analysis

## Project Overview
This project analyzes customer purchasing behavior using the Instacart dataset.  
The analysis focuses on customer loyalty, reorder behavior, basket size patterns, purchasing trends, and department-level sales insights.

The project was completed using SQL, DuckDB, Python, Pandas, and Matplotlib inside Jupyter Notebook.

---

# Objectives
- Analyze customer purchasing behavior
- Identify peak shopping days and hours
- Study reorder trends across loyalty groups
- Analyze basket size behavior
- Discover top-performing departments
- Generate business recommendations using data insights

# Key Business Insights
- Loyal customers showed significantly higher reorder rates.
- Produce and dairy departments generated the highest purchase volumes.
- Most customer orders occurred during daytime shopping hours.
- Casual customers placed smaller baskets compared to loyal customers.
- Customer purchasing activity varied across different weekdays.

---

# Business Recommendations
- Offer personalized promotions to casual customers to improve retention.
- Focus marketing campaigns during peak shopping hours.
- Prioritize inventory management for high-demand departments.
- Create loyalty-based discount programs to increase repeat purchases.
